# v0.1.0 · 首次发布

简体中文的个人动画制作管理工具，采用 Python、Streamlit 与 SQLite，无需 GPU 或 API Key。

- 剧集、角色、场景与镜头任务管理。
- 图片、视频与音频素材预览，跨角色/剧集引用。
- 音乐版本审阅、最终采用标记、历史文件和歌词比较。
- 搜索筛选、制作统计、完整备份与恢复。
- 回收站、删除确认、恢复、重复内容提示与定向永久删除。
- 纯合成演示数据、中文 README、Windows/Linux 启动脚本及自动测试。

采用 MIT 许可证。仓库不含真实剧本、角色设计、歌曲、成片或生产数据库；第三方依赖保留各自许可证。

使用 Python 3.11，Windows 双击 `start.bat`；其他平台请按 README 安装和运行。应用适合本机或平台登录保护下的个人使用，不提供公网认证功能。ModelScope 的端口预览需在实际账户中确认。
