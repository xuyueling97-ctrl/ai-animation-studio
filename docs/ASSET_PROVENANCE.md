# 演示与测试素材来源

- `demo.py`：自制生成器。几何图形使用 Pillow 绘制，WAV 为一秒全零采样，台词为标注“虚构演示”的两句占位文字；不读取外部文件或真实项目。
- `tests/fixtures/preview.mp4`：开发过程中用 FFmpeg 的 `color` 滤镜生成的 160×90、约 0.5 秒单色 H.264 测试片段，不包含实拍、角色、音乐或第三方作品内容。仓库不分发 FFmpeg 程序。
- `docs/screenshots/overview.png`：从独立合成演示项目运行时截取，隐藏本机数据目录，不展示个人资料。
- `docs/third-party-licenses/`：对应安装依赖附带的许可/NOTICE 原文；Streamlit 文本来自明确的 1.51.0 上游标签。它们是第三方许可声明，不是本项目的原创许可文本。

项目代码、自制演示与截图采用根目录 MIT 许可证；第三方许可声明保留其原有属性。原作实际制作素材不在仓库中。
